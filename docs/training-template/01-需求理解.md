## 需求概述

在现有 nanoGPT 仓库里沉淀一套**教学 / 开源向的模型训练模板**：以可复用包 `src/trainer`（导入名 `import trainer`）承载训练主干——可插拔的模型与数据集、声明式配置、完整日志与评估、断点续训、内置超参搜索与性能基准。

目标不是再造一个训练框架，而是提供一份**读得懂、改得动、跑得通**的最小完整训练闭环：新架构（RNN / CNN / 扩散）或新数据集都能按固定契约接入，读者可以从 `trainer/train.py` 一路读到底。整个模板不提供命令行工具，四条命令就是四个模块入口。

## 需求来源（问答结论）

| 议题 | 结论 |

| 入口 | 各模块自成一个入口 `python -m trainer.train|sample|bench|sweep <config.toml>`，**不提供 CLI / console script** |
| 模型通用性 | 可插拔注册表，统一接口，能接新架构 |
| 数据接入 | 抽象 Dataset 接口，`.bin` memmap 只是其中一种实现 |

| 使用场景 | 教学 / 开源模板，可读性优先 |
| sweep | 内置网格 / 随机搜索 + 结果汇总表（零外部依赖），搜索空间写在配置里 |
| 根脚本 | `train.py` / `sample.py` / `bench.py` / `model.py` 完全不动，新包并行存在 |
| 本期范围 | 仅文档（01 需求 + 02 方案），不写实现 |

## 功能需求

### P0 — 必须实现

- [ ] 模型注册表：`@register_model("gpt")` 声明 + `build_model(name, vocab_size)` 构建；每个模型实现统一契约（前向、生成、参数量）
- [ ] 开箱可用的 GPT：以适配器包装根目录 `model.py` 的 `GPT`，不复制第二份实现
- [ ] 数据集契约：`get_batch(split, batch, block, device)` + `encode/decode` + `vocab_size`
- [ ] `MemmapDataset`：读取 `data/<name>/{train,val}.bin` 与 `meta.pkl`，与现有数据格式兼容
- [ ] 配置：dataclass 配置树（data / model / optim / train / run / log / sample / bench / sweep）+ TOML 文件作为**唯一配置来源**，启动时校验（未知键、类型不符、取值非法都拦下）
- [ ] 模块入口：`python -m trainer.train` / `trainer.sample` / `trainer.bench` / `trainer.sweep`，各接受一个可选位置参数（配置文件路径，缺省 `configs/debug_cpu.toml`），多传参数直接报错退出
- [ ] 训练循环：梯度累积、混合精度（bf16 / fp16+GradScaler）、warmup+cosine 学习率、梯度裁剪
- [ ] 周期评估与指标：train loss、val loss、perplexity、next-token accuracy、lr、grad norm、tokens/s
- [ ] 日志多路输出：控制台、`metrics.jsonl`、TensorBoard、wandb（默认关闭）
- [ ] 断点续训：单文件 `ckpt.pt`（model / optimizer / scaler / step / config / dataset meta），`run.resume=auto` 自动接续，也可填显式路径
- [ ] 训练结束自动采样：生成文本写入 `samples.txt` 并打印一段

### P1 — 重要

- [ ] `bench`：固定步数测 step time、tokens/s，可选 MFU 估算，不写 checkpoint（步数来自 `[bench]`）
- [ ] `sweep`：从 `[sweep].space` 展开网格 / 随机搜索，每组实验生成独立 `config.toml` 与 run 目录（以子进程调 `trainer.train` 执行），输出 `summary.csv` / `summary.md`（按 val loss 排序）
- [ ] `HFDataset`：HuggingFace datasets 数据源（`datasets` 已在依赖中）
- [ ] 示例配置：CPU debug、单卡小模型、shakespeare_char、一个 sweep 配置
- [ ] 教学向文档：README 一节 + 每个模块顶部一段「这个文件在做什么」

### P2 — 可选

- [ ] DDP 多卡（本期不做，训练循环中预留分布式钩子注释）
- [ ] 精确 MFU / FLOPs 统计、EMA 权重、early stopping

## 非功能需求

- **可读性**：单文件单一职责；`train.py` 核心循环目标 ≤ 250 行；中文文档 + 中文行内注释；拒绝隐式魔法（不引入 hydra / lightning / argparse 体系）
- **可复现性**：run 目录里的 `config.toml` 就是该次实验的完整定义，复制这一个文件即可重跑；不存在「命令行与文件不一致」的状态
- **兼容性**：不修改根目录 `train.py` / `sample.py` / `bench.py` / `model.py` / `configurator.py` / `config/*.py`，`git status` 对这些路径保持干净
- **依赖**：仅新增 `tensorboard`；不引入 optuna / hydra / lightning / accelerate / click / typer
- **可跑性**：CPU + debug 配置 60 秒内跑完 20~50 步，无需网络、无需 wandb 登录
- **确定性**：固定 `seed` 后同配置两次短跑，首步 loss 完全一致（单进程单卡）
- **健壮性**：`resume` 无权重、数据缺失、配置字段拼错或类型写错，都必须给出可读中文错误而非 KeyError 堆栈

## 边界与约束

- **不提供命令行工具**：没有 CLI 层、没有 console script、没有 `--lr` 这类快捷参数；启动方式固定为「模块 + 可选配置文件路径」，改参数就是改 TOML
- **包重命名的连带影响**：现有 `nanogpt` 命令（只打印问候语）随包重命名一起消失，`pyproject.toml` 的 `[project.scripts]` 需删除；发行名 `nanogpt` 保持不变，只改导入名
- **不包含**：DDP / FSDP / 分布式检查点、SFT / 分类等非 LM 任务的专用 trainer、自建实验追踪 Web UI、多份配置的继承 / include 语法
- **技术限制**：Python 3.13、PyTorch、`uv_build` 打包；配置小节固定为 data / model / optim / train / run / log / sample / bench / sweep
- **外部依赖**：wandb 默认 `enabled=false`，冒烟测试与验证不触发联网；HF 数据源需要本地缓存或网络
- **凭据**：模板不读取任何凭据文件，wandb key 由环境变量提供

## 验收标准

### 训练闭环

- Given 已准备 `data/shakespeare_char/{train,val}.bin` + `meta.pkl`，When 执行 `python -m trainer.train configs/debug_cpu.toml`，Then 20~50 步内正常结束，`runs/<name>/` 下出现 `ckpt.pt`、`metrics.jsonl`、`tb/events.out.tfevents.*`、`config.toml`，且末段 train loss 低于首步
- Given 训练在 N 步后被中断，When 保持该次 `config.toml` 的 `[run] resume="auto"` 重新执行同一条命令，Then 从 N+1 步继续，日志打印恢复的 step 与 loss
- Given 不传任何路径，When 执行 `python -m trainer.train`，Then 使用 `configs/debug_cpu.toml` 默认配置

### 入口约束

- Given 执行 `python -m trainer.train configs/debug_cpu.toml extra.pth`，When 多传了一个参数，Then 立即报错（中文，提示只接受一个配置文件路径）并以退出码 1 结束，不启动训练
- Given 配置里把键名写成 `max_iter`（正解 `max_iters`），When 执行训练入口，Then 启动阶段即失败，报错指出未知键并给出最接近字段名，不进入训练
- Given 配置里 `[optim] lr = "high"`，When 执行训练入口，Then 报错指出类型不符（期望 float）

### 配置唯一来源

- Given 任意 run 目录，When 只保留其中的 `config.toml` 并重新执行 `python -m trainer.train <该文件>`，Then 训练超参与原实验完全一致

### 指标与可视化

- Given 训练跑过 `eval_interval` 步，When 用 `tensorboard --logdir runs` 打开，Then 能看到 `train/loss`、`val/loss`、`val/perplexity`、`val/accuracy`、`lr` 五条曲线
- Given 训练结束，When 查看 `metrics.jsonl`，Then 每行是合法 JSON 且至少含 `step`、`split`、`loss`

### 采样

- Given `[sample]` 中填了 prompt（ckpt 缺省指向 `runs/<run.name>/ckpt.pt`），When 执行 `python -m trainer.sample configs/debug_cpu.toml`，Then 输出可读文本并写入 `samples.txt`；字符级数据集自动使用 `meta.pkl` 的 `stoi/itos`

### 可插拔性

- Given 新增一个实现统一契约的 toy 模型，When 在 `models/` 下注册并在配置写 `model.name="toy_rnn"`，Then 训练、评估、采样全流程无需改动训练器代码即可跑通

### sweep 与 bench

- Given `[sweep]` 中 `space = { "optim.lr" = [1e-3, 3e-4], "model.n_layer" = [2, 4] }`，When 执行 `python -m trainer.sweep configs/sweep_lr.toml`，Then 生成 4 个独立 run 目录（每个内含自己的 `config.toml`）与 `summary.csv`，表内含 lr、n_layer、best val loss 列，且按 val loss 升序
- Given 任意可训练配置，When 执行 `python -m trainer.bench configs/debug_cpu.toml`（步数取 `[bench].iters`），Then 打印平均 step time 与 tokens/s，且不写 checkpoint

### 回归

- Given 新包已落地，When 对仓库根执行 `git status`，Then `train.py` / `sample.py` / `model.py` / `config/*.py` 无改动；`uv run nanogpt` 不再存在（已知破坏）
