## 技术方案概述

在 `src/nanogpt/` 下实现一套**扁平、可读优先**的训练骨架：三个小契约（`TrainableModel` / `BatchSource` / `Logger`）撑起可插拔性，一棵 dataclass 配置树读取**一份 TOML**撑起可复现性，一个 250 行以内的训练循环撑起主干。`gpt` 模型以适配器方式复用根目录 `model.py`，`memmap` 数据集复用现有 `.bin + meta.pkl` 格式，因此新包与根脚本并行存在、互不影响。CLI 统一为 `nanogpt <train|sample|bench|sweep>`，**只指向配置文件**，不提供任何字段级覆盖。

设计原则：**能删就删**——不引入 hydra / lightning / optuna / accelerate；没有命令行覆盖层，就没有字符串解析、类型转换、优先级规则这三类分支；sweep 用 subprocess 隔离而非进程内调度；TensorBoard 用 `torch.utils.tensorboard`（只需补一个 `tensorboard` 依赖）；DDP 本期不做，只在循环里留一行注释说明扩展点。

## 技术选型

| 类别 | 选择 | 理由 |
|------|------|------|
| 语言 / 运行时 | Python 3.13 + PyTorch | 仓库既有栈，`.python-version` 已固定 |
| 配置 | dataclass 树 + stdlib `tomllib` 读 TOML，**无 CLI 覆盖** | 一份文件 = 一次实验：可 diff、可归档、可直接当复现入口；无需解析 `k=v` 与类型转换 |
| CLI | `argparse` 子命令，仅收 `--config` 与运行期输入 | stdlib，教学可读；不上 click/typer |
| 模型组织 | 注册表 + `Protocol` | 新架构零侵入接入，GPT 走适配器避免两份实现漂移 |
| 数据组织 | `BatchSource` 契约 + 工厂 | `.bin` 只是默认实现，HF / 分类数据按同一接口扩展 |
| 日志 | 控制台 + `metrics.jsonl` + TensorBoard + wandb（可关） | 本地永远可复现，可视化按需开启，默认不联网 |
| 打包 | `uv_build`（既有） | 新增 console script 即可 |
| 超参搜索 | 内置 grid/random + subprocess + CSV 汇总 | 零依赖、失败隔离、结果可直接贴进报告 |

## 架构设计

```
┌──────────────────────────── CLI 层（cli.py）────────────────────────────┐
│ nanogpt train|sample|bench|sweep --config <toml> [运行期输入]           │
│ 只做两件事：定位配置文件、把 runtime 输入交给对应子命令                  │
└───────────────┬─────────────────────────────────────────────┬──────────┘
                │                                             │
┌───────────────▼──────────────┐              ┌───────────────▼──────────┐
│ 配置层 configs.py            │              │ 组合层                   │
│ Config 树 / TOML 读取 / 校验 │              │ registry.build_model     │
│ （无覆盖、无合并、无继承）    │              │ data.build_dataset       │
└───────────────┬──────────────┘              │ loggers.build_loggers    │
                │                             └───────────┬──────────────┘
┌───────────────▼─────────────────────────────────────────▼──────────────┐
│ 主干层 trainer.py：AMP + 梯度累积 + lr 调度 + 周期评估 + 存档 + 采样     │
│ 支撑：checkpoint.py（存取/续训） sampler.py benchmark.py sweep.py        │
└───────────────┬────────────────────────────────────────────────────────┘
                │
┌───────────────▼──────────────┐  ┌──────────────────────┐  ┌────────────┐
│ 契约层 protocols.py          │  │ models/（gpt, toy）  │  │ data/      │
│ TrainableModel/BatchSource   │  │ @register_model      │  │ memmap, hf │
│ Logger                       │  │                      │  │            │
└──────────────────────────────┘  └──────────────────────┘  └────────────┘
```

- **不做分层抽象**：配置 → 组装 → 主干 → 契约，四层就到顶，没有 service / manager / plugin 体系。
- **依赖方向单向向下**：`cli → configs → 组装 → trainer → protocols`，`models/` 与 `data/` 只依赖 `protocols` 与 `configs`，互不引用。
- **契约是唯一扩展点**：新增模型 / 数据集只改 `models/`、`data/` 下的一个文件 + 一行注册，训练器不改。
- **配置是唯一事实来源**：`Config` 一旦构造完成就是不可变语义（`dataclass(frozen=True)`），训练器不再接受外部参数。

```
├── benchmark.py           # step time / tokens per sec / 参数量
├── sweep.py               # 从 [sweep].space 展开 → 生成每组 config.toml → 子进程 → 汇总
├── utils.py               # 种子、设备与 dtype 选择、目录创建等小工具
├── models/
│   ├── __init__.py        # import 即注册（gpt、toy_rnn）

└── data/
    ├── __init__.py        # import 即注册（memmap、hf）
    ├── memmap.py          # .bin + meta.pkl（np.memmap，默认实现）
    └── hf.py              # HuggingFace datasets（P1，可选依赖保持现状）
```

| 模块 | 职责 | 依赖 |
|------|------|------|
| `cli.py` | 解析 `--config` 与运行期输入、子命令分发、错误转中文提示 | configs |
| `configs.py` | 配置定义、TOML 读取、校验 | — |
| `protocols.py` | 三个契约定义 | — |
| `registry.py` | 名称 → 构建函数映射 | protocols, configs |
| `trainer.py` | 训练循环、评估、指标、存档触发 | protocols, checkpoint, loggers |
| `checkpoint.py` | 存档读写、续训定位 | configs |
| `loggers.py` | 指标分发到各 sink | protocols |
| `sampler.py` | 生成文本、解码 | protocols, data |
| `benchmark.py` | 性能测量 | trainer 的 build 路径 |
| `sweep.py` | 生成每组配置、子进程编排、汇总 | cli（以子进程方式） |

## 接口设计

### 契约 1：TrainableModel

```python
@runtime_checkable
class TrainableModel(Protocol):
    block_size: int
    vocab_size: int
    def __call__(self, idx: Tensor, targets: Tensor | None = None) -> tuple[Tensor, Tensor | None]: ...
    def generate(self, idx: Tensor, max_new_tokens: int,
                 temperature: float = 1.0, top_k: int | None = None) -> Tensor: ...
    def num_params(self) -> int: ...
```

沿用根 `model.py` 的既有约定：**带 targets 返回全序列 logits + loss，不带 targets 只返回最后一步 logits 且 loss 为 None**（AGENTS 中的探针依赖此行为）。

### 契约 2：BatchSource

```python
class BatchSource(Protocol):
    vocab_size: int
    def get_batch(self, split: Literal["train", "val"], batch_size: int,
                  block_size: int, device: str) -> tuple[Tensor, Tensor]: ...
    def encode(self, text: str) -> list[int]: ...
    def decode(self, ids: list[int]) -> str: ...
```

目标张量由实现负责右移一位，训练器不做 token 语义假设（为 diff 类任务留出口）。

### 契约 3：Logger

```python
class Logger(Protocol):
    name: str
    def log(self, step: int, metrics: dict[str, float], split: str = "train") -> None: ...
    def close(self) -> None: ...
```

### 注册表

```python
@register_model("gpt")            # models/__init__.py 里 import 即生效
def build_gpt(cfg: ModelConfig, vocab_size: int) -> TrainableModel: ...

build_model(cfg.model, vocab_size)   # 未注册 → 中文报错并列出现有名称
build_dataset(cfg.data)              # 同上
```

### CLI 契约（无配置覆盖）

```
nanogpt train  --config configs/debug_cpu.toml
nanogpt sample --config configs/debug_cpu.toml [--ckpt runs/debug/ckpt.pt] [--prompt "ROMEO:"]
nanogpt bench  --config configs/debug_cpu.toml
nanogpt sweep  --config configs/sweep_lr.toml
```

| 参数 | 性质 | 缺省来源 |
|------|------|----------|
| `--config` | 必填，唯一配置入口 | — |
| `--ckpt` | 运行期输入 | `[sample].ckpt` → 缺省 `runs/<run.name>/ckpt.pt` |
| `--prompt` | 运行期输入 | `[sample].prompt` |

- 不存在 `--set`、`--lr`、`--max-iters` 这类字段级参数；改训练超参 = 改 TOML。
- `sample` 的生成超参（`max_new_tokens` / `temperature` / `top_k`）只来自 `[sample]`，命令行不出现。
- `bench` 的 `iters` / `warmup` 只来自 `[bench]`。
- `sweep` 的搜索空间、模式、采样数只来自 `[sweep]`。
- 退出码：0 成功，1 配置 / 数据错误（中文提示），2 运行期异常。

### 运行期目录契约

```
runs/<run.name>/
├── ckpt.pt          # 最新权重（原子写：.tmp → os.replace）
├── metrics.jsonl    # 每行 {"step","split","loss","perplexity","accuracy",...}
├── samples.txt      # 训练结束采样结果（含 prompt 与输出）
├── config.toml      # 生效配置快照：该 run 的唯一复现入口
└── tb/              # TensorBoard 事件文件（tensorboard --logdir runs 一次看全部）
```

### checkpoint 数据契约

```python
{
  "model": state_dict, "optimizer": state_dict, "scaler": state_dict | None,
  "step": int, "best_val_loss": float,
  "config": asdict(Config),                    # 完整配置，续训不依赖外部文件
  "dataset": {"name": str, "vocab_size": int, "meta_pkl": str | None},
}
```

`run.resume`：`auto`（存在即接续）/ `none`（从零，并覆盖旧存档）/ 显式路径。

## 数据模型（配置）

```python
@dataclass(frozen=True)
class DataConfig:     name="shakespeare_char"; root="data"; batch_size=12; block_size=256; num_workers=0
@dataclass(frozen=True)
class ModelConfig:    name="gpt"; n_layer=4; n_head=4; n_embd=128; dropout=0.0; bias=True; extras={}
@dataclass(frozen=True)
class OptimConfig:    lr=1e-3; weight_decay=0.1; betas=(0.9,0.95); grad_clip=1.0;
                      warmup_iters=50; lr_decay_iters=500; min_lr=1e-4
@dataclass(frozen=True)
class TrainConfig:    max_iters=500; grad_accum=1; amp="none"|"bf16"|"fp16"; eval_interval=100;
                      eval_iters=20; log_interval=10; seed=1337
@dataclass(frozen=True)
class RunConfig:      out_root="runs"; name="debug"; resume="auto"; save_interval=100;
                      sample_after_train=True; sample_prompt="\n"
@dataclass(frozen=True)
class LogConfig:      console=True; file=True; tensorboard=True; wandb=False; wandb_project="nanogpt-template"
@dataclass(frozen=True)
class SampleConfig:   ckpt=None; prompt="\n"; max_new_tokens=200; temperature=1.0; top_k=None
@dataclass(frozen=True)
class BenchConfig:    iters=10; warmup=3
@dataclass(frozen=True)
class SweepConfig:    name="sweep"; mode="grid"|"random"; space: dict[str, list]; num_samples=8

@dataclass(frozen=True)
class Config:  data; model; optim; train; run; log; sample; bench; sweep
    @classmethod
    def load(cls, path: str) -> "Config"        # TOML → 构造 → validate()
    def to_toml(self) -> str                    # 写 run 目录快照 / sweep 生成子配置
```

`configs/debug_cpu.toml` 示例：

```toml
[data]
name = "shakespeare_char"
batch_size = 8
block_size = 128

[model]
name = "gpt"
n_layer = 2
n_head = 2
n_embd = 64

[train]
max_iters = 40
amp = "none"          # CPU 上用 none 或 bf16

[run]
name = "debug-cpu"
resume = "none"

[log]
tensorboard = true
wandb = false
```

`sweep` 配置示例：

```toml
# configs/sweep_lr.toml —— 其余小节与普通训练配置一致
[sweep]
name = "lr-nlayer"
mode = "grid"
space = { "optim.lr" = [1e-3, 3e-4], "model.n_layer" = [2, 4] }
num_samples = 8        # 仅 random 模式使用

[train]
max_iters = 100
```

校验规则（`validate()`，全部在 `Config.load` 内完成）：`n_embd % n_head == 0`；`data.block_size <= model.block_size`；`amp == "fp16"` 且 `device == "cpu"` → 明确报错；`optim.min_lr <= optim.lr`；未知 TOML 键 → `ConfigError` 并用 `difflib.get_close_matches` 给拼写建议；类型不符 → 报出期望类型与实际值；`[sweep].space` 的键必须是合法配置路径，且在 sweep 启动时一次性全部校验。

## 关键设计决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 配置变更方式 | 只改 TOML，无 CLI 覆盖 | 一份文件即一次实验，可 diff / 归档 / 直接当复现入口；省掉字符串解析与类型转换一整层代码 |
| sample/bench 参数位置 | 进 `[sample]` / `[bench]` 小节 | 保持「CLI 零超参」一致性；命令短到能背 |
| 是否复用根 `model.py` | 适配器惰性 import，不复制实现 | 避免两份 GPT 漂移；AGENTS 的 forward/backward 探针继续有效 |
| 是否上 DDP | 本期不做，留一行扩展注释 | 用户未选；教学模板优先单卡可读 |
| 训练循环 | 自写，不引入 Lightning | 备课友好：200 余行读完即懂 |
| sweep 运行方式 | 生成每组 `config.toml` + subprocess | 完全复用「配置即入口」；显存/全局状态天然隔离，单组崩溃不污染整轮 |
| 指标口径 | loss / ppl = exp(loss) / next-token accuracy | LM 三条最有信息量的曲线 |
| TensorBoard 与 wandb | TB 默认开、wandb 默认关 | 本地可视化零配置；验证流程不联网 |
| 存档粒度 | 单文件最新 ckpt（不保留历史） | 教学模板不需要滚动留存 |
| 日志接口 | 全量 metrics 字典 + 空实现 sink | 新增 sink 不改训练器 |

## 实现计划

1. **骨架**：包目录、`configs.py`（含全部小节与 `validate`）、`protocols.py`、`registry.py`、`cli.py` 空转、`configs/debug_cpu.toml`。验收：`nanogpt train --config …` 打印配置快照后退出（退出码 0）；拼错键时报中文错误。
2. **数据与模型**：`data/memmap.py`、`models/gpt.py`、`models/toy_rnn.py`。验收：一个 batch 形状正确；AGENTS 的 `model.py` 探针仍通过。
3. **训练主干**：`trainer.py`（AMP / 累积 / warmup+cosine / 评估 / 梯度裁剪）、`checkpoint.py`、续训。验收：CPU 40 步 loss 下降；中断后 `resume=auto` 从下一步继续。
4. **日志**：`loggers.py` 四个 sink。验收：`tb/` 事件含 `train/loss`、`val/loss`、`val/perplexity`、`val/accuracy`、`lr`；`metrics.jsonl` 每行合法 JSON；`wandb=false` 不联网。
5. **采样与 bench**：`sampler.py`、`benchmark.py`（参数取 `[sample]` / `[bench]`）。验收：`sample` 输出可读文本；`bench` 打印 step time 与 tokens/s 且不写 ckpt。
6. **sweep**：`sweep.py`——`space` 展开 → 每组写 `runs/<sweep.name>/<run_id>/config.toml`（`run_id` 形如 `lr=3e-4__n_layer=4`，目录名即超参）→ 子进程 `python -m nanogpt train --config <该文件>` → 读各组 `metrics.jsonl` 末行汇总。验收：2×2 网格生成 4 个目录 + `summary.csv` / `summary.md` 按 val loss 排序。
7. **文档与示例**：README 一节、四档配置（debug / 单卡小模型 / shakespeare_char / sweep）、toy 模型接入示例。
8. **回归**：`git status` 根脚本无改动；根 `test.py` 演示仍可运行（数据存在时）。

## 风险与待确认

| 风险 | 影响 | 应对 |
|------|------|------|
| 无 CLI 覆盖，微调单个参数要编辑文件 | 交互式试错变慢 | 刻意取舍：用 run 目录 `config.toml` 复制改写 + sweep 自动生成；需要临时试参时推荐「复制 → 改一处 → 跑」 |
| 根 `model.py` 只能从仓库根导入 | 装成包后找不到 `gpt` 模型 | 文档明示从仓库根运行 `python -m nanogpt`；`pip install -e .` 场景报可读中文错误 |
| 新增 `tensorboard` 依赖 | `uv.lock` 变动 | `uv add tensorboard` 一次完成并提交锁文件 |
| 通用性抬高阅读成本 | 与「教学可读」冲突 | 主干保持直白，toy 模型 60 行演示接入；每文件顶部一句话说明职责 |
| fp16 在 CPU 不可用 | 误配置时崩溃 | 校验阶段拦截并提示 `none` / `bf16` |
| `metrics.jsonl` 与 TB 双写不一致 | 汇总口径分歧 | 同一 metrics 字典喂所有 sink，sweep 只读 jsonl 末行 |
| 模板膨胀 | 变成半个框架 | README 写明：新增能力优先以示例形式加入，而非新配置项 |
