本手册对应 `src/trainer/` 的实际实现：**四条命令 + 一份 TOML**，没有任何命令行开关。

## 1. 前提

| 项 | 要求 |
|----|------|
| 工作目录 | **仓库根目录**（`gpt` 模型会惰性 import 根目录的 `model.py`） |
| 数据 | `data/<name>/train.bin`、`val.bin`，可选 `meta.pkl`（有则按字符级 itos/stoi，无则按 GPT-2 分词） |
| 依赖 | `torch`、`tensorboard`（已在 `pyproject.toml`）；wandb 仅在 `[log] wandb=true` 时用到 |
| 打包 | `src/` 已在 `sys.path`（`nanogpt.pth`），所以 `python -m trainer.*` 直接可用 |

字符级莎士比亚数据已经准备好；其它数据集跑各自的 `prepare.py`，例如：

```sh
python data/shakespeare_char/prepare.py
```

## 2. 四条命令

```sh
python -m trainer.train  [config.toml]   # 训练
python -m trainer.sample [config.toml]   # 采样
python -m trainer.bench  [config.toml]   # 性能基准
python -m trainer.sweep  [config.toml]   # 超参搜索
```

- 位置参数只有一个：配置文件路径；**不写**则用 `configs/debug_cpu.toml`。
- 没有 `--lr`、`--set`、`--config` 这类开关。多传参数会直接报错退出：
  ```
  配置/数据错误：只接受一个配置文件路径，收到多余参数：['extra.pth']
  ```
- 退出码：`0` 成功；`1` 配置或数据问题（已打印中文原因）；`2` 未预期异常（保留完整堆栈）。
- 用 `uv` 管理环境时写法是 `uv run python -m trainer.train configs/debug_cpu.toml`——`uv run trainer.train` 会把 `trainer.train` 当命令去找，报 `Failed to spawn`。

## 3. 一次训练做了什么

1. 读 TOML → 校验（类型、取值、未知键、`n_embd % n_head`、`data.block_size <= model.block_size`、CPU 上的 fp16 等）。
2. 建数据集与模型，按 `[run] device` 选设备（`auto` = 有 GPU 就用）。
3. 把生效配置写成 `runs/<run.name>/config.toml`（快照）。
4. 训练循环：梯度累积 → 混合精度 → 梯度裁剪 → AdamW；学习率 warmup + cosine。
5. 每 `log_interval` 步记训练指标；每 `eval_interval` 步评估 val 并存档。
6. 结束时按 `[run] sample_after_train` 采样写 `samples.txt`。

真实日志长这样（`configs/debug_cpu.toml`，40 步）：

```
step     0 | train | loss 4.193 | accuracy 0.02637 | lr 0.0001 | grad_norm 2.371 | tokens_per_sec 1762
step     0 | val   | loss 4.169 | perplexity 64.66 | accuracy 0.02871
...
step    39 | val   | loss 3.226 | perplexity 25.17 | accuracy 0.2104

训练结束：已到第 39 步，最好 val loss 3.2257，存档 runs/debug-cpu/ckpt.pt
```

## 4. 产物

```
runs/<run.name>/
├── ckpt.pt          # 最新存档：模型 / 优化器 / scaler / step / best_val_loss / 配置 / 数据集信息
├── metrics.jsonl    # 每行一条 JSON，含 step、split 与全部指标（sweep 汇总读这个）
├── config.toml      # 生效配置快照，复制它就能复现整次实验
├── samples.txt      # 采样结果
└── tb/              # TensorBoard 事件文件
```

一次 train 的 train 指标：`loss`、`accuracy`、`lr`、`grad_norm`、`tokens_per_sec`；
val 指标：`loss`、`perplexity`、`accuracy`。

看曲线：

```sh
tensorboard --logdir runs
```

## 5. 配置参考

所有字段都可以省略，省略时用默认值；**写错键名会直接报错并给出最接近的字段名**。

### `[data]`

| 字段 | 默认 | 说明 |
|------|------|------|
| `name` | `shakespeare_char` | 数据集目录名（位于 `root` 下） |
| `root` | `data` | 数据根目录 |
| `reader` | `memmap` | 数据实现：`memmap`（.bin）或 `hf`（HuggingFace，需联网） |
| `batch_size` | `12` | 每个 micro-batch 的样本数 |
| `block_size` | `256` | 上下文长度，不能超过 `[model] block_size` |

### `[model]`

| 字段 | 默认 | 说明 |
|------|------|------|
| `name` | `gpt` | 注册名：`gpt`（根目录 model.py）或 `toy_rnn` |
| `block_size` | `256` | 模型最大位置数 |
| `n_layer` `n_head` `n_embd` | `4` `4` `128` | 层数 / 头数 / 隐藏维（`n_embd % n_head == 0`） |
| `dropout` | `0.0` | dropout 概率 |
| `bias` | `true` | Linear/LayerNorm 是否带 bias |
| `extras` | `{}` | 给具体模型自由使用的额外键值，例如 `{ "hidden_scale" = 4 }` |

### `[optim]`

| 字段 | 默认 | 说明 |
|------|------|------|
| `lr` | `1e-3` | 峰值学习率 |
| `min_lr` | `1e-4` | cosine 末端学习率（不能大于 `lr`） |
| `weight_decay` | `0.1` | 只作用于二维参数（权重），bias/LayerNorm 不衰减 |
| `betas` | `[0.9, 0.95]` | AdamW betas（TOML 里写列表） |
| `grad_clip` | `1.0` | 梯度裁剪阈值，`0` 表示不裁剪 |
| `warmup_iters` | `50` | 线性预热步数 |
| `lr_decay_iters` | `500` | cosine 衰减到 `min_lr` 的步数 |

### `[train]`

| 字段 | 默认 | 说明 |
|------|------|------|
| `max_iters` | `500` | 总优化步数（按优化器步计，不是 micro-batch） |
| `grad_accum` | `1` | 梯度累积步数 |
| `amp` | `none` | `none` / `bf16` / `fp16`；`fp16` 仅 GPU |
| `eval_interval` | `100` | 每隔多少步评估 + 存档 |
| `eval_iters` | `20` | 评估时取多少个 val batch 取平均 |
| `log_interval` | `10` | 每隔多少步打训练指标 |
| `seed` | `1337` | 随机种子 |

### `[run]`

| 字段 | 默认 | 说明 |
|------|------|------|
| `out_root` | `runs` | 输出根目录 |
| `name` | `debug` | 本次实验名，产物落在 `out_root/name/` |
| `device` | `auto` | `auto` / `cpu` / `cuda`（也可 `cuda:1`） |
| `resume` | `auto` | `auto`=有存档就接续；`none`=从零重跑；其它值当存档路径 |
| `save_interval` | `100` | 额外存档间隔（评估时也会存） |
| `sample_after_train` | `true` | 训练结束自动采样 |

### `[log]`

| 字段 | 默认 | 说明 |
|------|------|------|
| `console` | `true` | 控制台打印指标 |
| `file` | `true` | 写 `metrics.jsonl` |
| `tensorboard` | `true` | 写 `tb/` |
| `wandb` | `false` | 打开后需 `WANDB_API_KEY`（本手册未验证该路径） |
| `wandb_project` | `trainer-template` | wandb 项目名 |

### `[sample]` / `[bench]` / `[sweep]`

| 小节 | 字段 | 默认 | 说明 |
|------|------|------|------|
| `[sample]` | `ckpt` | `""` | 空 = `runs/<run.name>/ckpt.pt` |
| | `prompt` | `"\n"` | 起始文本（字符级数据按字符编码） |
| | `max_new_tokens` | `200` | 生成长度 |
| | `temperature` | `1.0` | 采样温度 |
| | `top_k` | `0` | `0` = 不截断 |
| `[bench]` | `iters` | `10` | 计时步数 |
| | `warmup` | `3` | 预热步数（不计时） |
| `[sweep]` | `name` | `sweep` | 汇总目录名：`runs/<name>/` |
| | `mode` | `grid` | `grid` 全组合 / `random` 随机采样 |
| | `space` | `{}` | 形如 `{ "optim.lr" = [1e-3, 3e-4] }` |
| | `num_samples` | `8` | 仅 `random` 模式 |
| | `seed` | `0` | 仅 `random` 模式 |

## 6. 示例配置

最小可跑（CPU，40 步，一分钟内）：

```toml
[data]
name = "shakespeare_char"
batch_size = 8
block_size = 128

[model]
name = "gpt"
block_size = 128
n_layer = 2
n_head = 2
n_embd = 64

[optim]
lr = 1e-3
min_lr = 1e-4
warmup_iters = 10
lr_decay_iters = 40

[train]
max_iters = 40
amp = "none"
eval_interval = 20
eval_iters = 5
log_interval = 5

[run]
name = "debug-cpu"
resume = "auto"
device = "cpu"

[sample]
prompt = "\nROMEO:"
max_new_tokens = 60
```

`configs/` 下已备好三份：`debug_cpu.toml`（冒烟）、`shakespeare_char.toml`（单卡 6 层，`device="auto"`、`amp="bf16"`）、`sweep_lr.toml`（2×2 搜索）。

## 7. 常见任务

### 冒烟测试（确认环境没问题）

```sh
python -m trainer.train configs/debug_cpu.toml
```

### 换一个模型架构

1. 复制 `src/trainer/models/toy_rnn.py`，改类里的前向；
2. 保留 `@register_model("你的名字")` 与 `num_params()`；
3. 配置里写 `[model] name = "你的名字"`。

训练器、采样、bench 都不用改（`ToyRNN` 就是这样接进去的，49 行）。

### 换数据集

1. 准备 `data/<名称>/{train,val}.bin`（`uint16`）与可选 `meta.pkl`；
2. 配置写 `[data] name = "<名称>"`。

### 从零重跑 / 续训

```toml
[run]
resume = "auto"    # 三选一：auto | none | 存档路径
```

- `"auto"`（默认）：有 `ckpt.pt` 就从它的下一步继续。
- `"none"`：忽略已有存档，从头跑（会覆盖同名目录里的存档）。
- `"runs/别的实验/ckpt.pt"`：从指定存档接续；路径不存在会在启动时报错。

续训日志会打印：`接续 runs/debug-cpu/ckpt.pt：从第 40 步继续，历史最好 val loss 3.2257`。
存档里的模型结构与当前 `[model]` 不一致时会直接报错并提示换回对应配置，不会静默加载一半权重。

### 复现某次实验

```sh
cp runs/debug-cpu/config.toml my_repro.toml   # 可改 [run] name，避免覆盖原产物
python -m trainer.train my_repro.toml
```

### 调超参

没有命令行覆盖：复制配置、改一处、跑。批量对比用 `sweep`。

### 找学习率（sweep）

```toml
[sweep]
name = "lr-nlayer"
mode = "grid"
space = { "optim.lr" = [3e-4, 1e-3], "model.n_layer" = [2, 4] }
```

```sh
python -m trainer.sweep configs/sweep_lr.toml
```

每组实验写到 `runs/<sweep.name>/<run_id>/`（目录名即超参，如 `n_layer=2__lr=0.001`），可覆盖的键只能是 `小节.字段`，启动时会一次性校验。结果：

```
| run_id | optim.lr | model.n_layer | val_loss | val_accuracy | status |
|---|---|---|---|---|---|
| n_layer=2__lr=0.001 | 0.001 | 2 | 3.51348 | 0.161133 | ok |
| n_layer=1__lr=0.001 | 0.001 | 1 | 3.53571 | 0.157878 | ok |
```

同时生成 `summary.csv` 与 `summary.md`（按 val loss 升序，失败组 `status=error`）。

### 测速

```sh
python -m trainer.bench configs/debug_cpu.toml
# 参数量 0.11M | 10 步平均 6.0 ms/step | 171,787 tokens/s
```

只做前向+反向，不写存档、不出日志。

## 8. 排错

| 提示 | 原因 | 处理 |
|------|------|------|
| `只接受一个配置文件路径，收到多余参数：['extra.pth']` | 多传了参数 | 只给配置文件路径 |
| `[train] 里出现了未知配置项 'max_iter'，是不是想写 'max_iters'？` | 键名拼错 | 按提示改名；注意没有 `--set` |
| `[optim] lr 需要数字，收到 'high'` | 类型不符 | 按默认类型写（数字不加引号） |
| `[train] amp="fp16" 需要 GPU；CPU 上请用 bf16 或 none` | fp16 依赖 CUDA | 改 `bf16` 或 `none` |
| `[sweep] optim 里没有 'lrr'，是不是想写 'lr'？` | space 键名错 | 写 `小节.字段` |
| `存档 ... 与当前配置不匹配（结构或参数量不同）` | `resume` 指向了别的模型/规模的存档 | 换回对应配置，或 `resume = "none"` |
| `缺少 data/shakespeare_char/train.bin ...` | 数据没准备 | 跑对应 `prepare.py` |
| `找不到根目录 model.py：请在仓库根目录运行` | 不在仓库根启动 | `cd` 到仓库根再执行 |
| `找不到存档 runs/.../ckpt.pt：先跑 python -m trainer.train` | sample 前没训练 | 先训练，或把 `[sample] ckpt` 指向已有存档 |
| `uv run` 报 `Expected a Python module at: src/nanogpt/__init__.py` | 发行名是 `nanogpt`，包目录却是 `src/trainer` | `pyproject.toml` 里已有 `[tool.uv.build-backend] module-name = "trainer"`，缺了就加上 |
| `error: Failed to spawn: trainer.train` | 把模块名当命令 | 写 `uv run python -m trainer.train ...` |

## 9. 已知限制

- **单卡**：不做 DDP/分布式检查点（训练循环里留了扩展注释）。
- **无命令行覆盖**：改任何超参都要动 TOML，这是刻意的取舍。
- **单文件存档**：只保留最新 `ckpt.pt`，不滚动保留历史；`best_val_loss` 记在文件里。
- **`[data] reader="hf"`**：会一次性把文本编码进内存，只适合小语料；本机未联网验证。
- **wandb 路径**：默认关闭，未在本次验证中开启。
- **`python -m trainer.sweep`**：每组都从头跑（内部强制 `resume="none"`），重跑会覆盖同名目录里的产物。

## 10. 与根脚本的关系

根目录 `train.py` / `sample.py` / `bench.py` / `model.py` / `configurator.py` / `config/` 完全保持原样，两边可以并存：根脚本用 `configurator.py` 的 `--key=value`，模板用 TOML。旧 console script（`nanogpt`，只打印问候语）已随包重命名删除，现在只有 `python -m trainer.*`。设计文档：`docs/training-template/01-需求理解.md`、`02-方案设计.md`。
