## 1. 前提

| 项 | 要求 |
|----|------|
| 工作目录 | **仓库根目录**（`gpt` 模型会惰性 import 根目录的 `model.py`） |
| 数据 | `data/<name>/train.bin`、`val.bin`（`uint16`），可选 `meta.pkl`（有则按字符级 itos/stoi，无则按 GPT-2 分词）；`[data] tokenizer` 可显式指定（见 §7） |
| 依赖 | `torch`、`tensorboard`（已在 `pyproject.toml`）；wandb 仅在 `[log] wandb=true` 时用到 |
| 打包 | `src/` 已在 `sys.path`（`nanogpt.pth`），所以 `python -m my_trainer.*` 直接可用 |

字符级莎士比亚数据已经准备好；其它数据集跑各自的 `prepare.py`，例如：

```sh
python data/shakespeare_char/prepare.py
```

## 2. 四条命令

```sh
python -m my_trainer.train  [config.toml]   # 训练
python -m my_trainer.sample [config.toml]   # 采样
python -m my_trainer.bench  [config.toml]   # 性能基准
python -m my_trainer.sweep  [config.toml]   # 超参搜索
```

- 位置参数只有一个：配置文件路径；**不写**则用 `configs/debug_cpu.toml`。
- 没有 `--lr`、`--set`、`--config` 这类开关。多传参数会直接报错退出：
  ```
  配置/数据错误：只接受一个配置文件路径，收到多余参数：['extra.pth']
  ```
- 退出码：`0` 成功；`1` 配置或数据问题（已打印中文原因）；`2` 未预期异常（保留完整堆栈）。
- 用 `uv` 管理环境时写法是 `uv run python -m my_trainer.train configs/debug_cpu.toml`——`uv run my_trainer.train` 会把 `my_trainer.train` 当命令去找，报 `Failed to spawn`。

## 3. 一次训练做了什么

1. 读 TOML → 校验（类型、取值、未知键、`n_embd % n_head`、`data.block_size <= model.block_size`、CPU 上的 fp16 等）。
2. 按 `[data] tokenizer_location` / `[model] location` import 自定义源码（里面的 `@register_*` 随之生效），再建数据集与模型，按 `[run] device` 选设备（`auto` = 有 GPU 就用）。
3. 把生效配置写成 `runs/<run.name>/config.toml`（快照）。
4. 训练循环：梯度累积 → 混合精度 → 梯度裁剪 → AdamW；学习率 warmup + cosine。
5. 每 `log_interval` 步记训练指标；每 `eval_interval` 步评估 val 并存档。
6. 结束时按 `[run] sample_after_train` 采样写 `samples.txt`。

默认 `[log] progress = true` 只有一条 tqdm 进度条（评估结果贴在右侧）；设成 `false` 才逐行打印，长这样（`configs/debug_cpu.toml`，40 步）：

```
step     0 | train | loss 4.193 | accuracy 0.02637 | lr 0.0001 | grad_norm 2.371 | tokens_per_sec 1762
step     0 | val   | loss 4.169 | perplexity 64.66 | accuracy 0.02871
...
step    39 | val   | loss 3.226 | perplexity 25.17 | accuracy 0.2104

训练结束：已到第 39 步，最好 val loss 3.2257，存档 runs/debug-cpu/ckpt.pt
```

## 4. 产物

```
runs/<run.name>/
├── ckpt.pt          # 最新存档：模型 / 优化器 / scaler / step / best_val_loss / 配置 / 数据集信息
├── metrics.jsonl    # 每行一条 JSON，含 step、split 与全部指标（sweep 汇总读这个）
├── config.toml      # 生效配置快照，复制它就能复现整次实验
├── samples.txt      # 采样结果
└── tb/              # TensorBoard 事件文件
```

一次 train 的 train 指标：`loss`、`accuracy`、`lr`、`grad_norm`、`tokens_per_sec`；
val 指标：`loss`、`perplexity`、`accuracy`。

看曲线：

```sh
tensorboard --logdir runs
```

## 5. 配置参考

所有字段都可以省略，省略时用默认值；**写错键名会直接报错并给出最接近的字段名**。

### `[data]`

| 字段 | 默认 | 说明 |
|------|------|------|
| `name` | `shakespeare_char` | 数据集目录名（位于 `root` 下） |
| `root` | `data` | 数据根目录 |
| `reader` | `memmap` | 数据实现：`memmap`（.bin）或 `hf`（HuggingFace，需联网） |
| `tokenizer` | `""` | 分词器：空=自动（meta.pkl→字符级，否则 GPT-2）；或 `类型:参数`：`tiktoken:p50k_base`、`hf:仓库id或本地目录`、自己 `@register_tokenizer` 的类型（词表须 ≤ 65535，见 §7） |
| `tokenizer_location` | `""` | 自定义分词器的实现源码：`.py` 路径（相对仓库根），import 时执行里面的 `@register_tokenizer`；内置类型留空 |
| `batch_size` | `12` | 每个 micro-batch 的样本数 |
| `block_size` | `256` | 上下文长度，不能超过 `[model] block_size` |

### `[model]`

| 字段 | 默认 | 说明 |
|------|------|------|
| `name` | `gpt` | 注册名：`gpt`（根目录 model.py）/ `toy_rnn` / `gpt_v0`（`src/gpt.py`）/ `gpt-v1`（`src/gptv1.py`）；自己的模型先用下面的 `location` 指定源码 |
| `location` | `""` | 模型实现源码：`.py` 路径（相对仓库根），import 时执行里面的 `@register_model`；内置模型留空 |
| `block_size` | `256` | 模型最大位置数 |
| `n_layer` `n_head` `n_embd` | `4` `4` `128` | 层数 / 头数 / 隐藏维（`n_embd % n_head == 0`） |
| `dropout` | `0.0` | dropout 概率 |
| `bias` | `true` | Linear/LayerNorm 是否带 bias |
| `extras` | `{}` | 给具体模型自由使用的额外键值，例如 `{ "hidden_scale" = 4 }` |

### `[optim]`

| 字段 | 默认 | 说明 |
|------|------|------|
| `lr` | `1e-3` | 峰值学习率 |
| `min_lr` | `1e-4` | cosine 末端学习率（不能大于 `lr`） |
| `weight_decay` | `0.1` | 只作用于二维参数（权重），bias/LayerNorm 不衰减 |
| `betas` | `[0.9, 0.95]` | AdamW betas（TOML 里写列表） |
| `grad_clip` | `1.0` | 梯度裁剪阈值，`0` 表示不裁剪 |
| `warmup_iters` | `50` | 线性预热步数 |
| `lr_decay_iters` | `500` | cosine 衰减到 `min_lr` 的步数 |

### `[train]`

| 字段 | 默认 | 说明 |
|------|------|------|
| `max_iters` | `500` | 总优化步数（按优化器步计，不是 micro-batch） |
| `grad_accum` | `1` | 梯度累积步数 |
| `amp` | `none` | `none` / `bf16` / `fp16`；`fp16` 仅 GPU |
| `compile` | `false` | `torch.compile` 训练前向；首次调用慢几十秒，换 batch/block 会重编译 |
| `eval_interval` | `100` | 每隔多少步评估 + 存档 |
| `eval_iters` | `20` | 评估时取多少个 val batch 取平均 |
| `log_interval` | `10` | 每隔多少步打训练指标 |
| `seed` | `1337` | 随机种子 |

### `[run]`

| 字段 | 默认 | 说明 |
|------|------|------|
| `out_root` | `runs` | 输出根目录 |
| `name` | `debug` | 本次实验名，产物落在 `out_root/name/` |
| `device` | `auto` | `auto` / `cpu` / `cuda`（也可 `cuda:1`） |
| `resume` | `auto` | `auto`=有存档就接续；`none`=从零重跑；其它值当存档路径 |
| `save_interval` | `100` | 额外存档间隔（评估时也会存） |
| `sample_after_train` | `true` | 训练结束自动采样 |

### `[log]`

| 字段 | 默认 | 说明 |
|------|------|------|
| `console` | `true` | 控制台输出（关闭后进度条也一起关） |
| `progress` | `true` | tqdm 进度条；右侧实时显示 loss / lr / val、ppl |
| `file` | `true` | 写 `metrics.jsonl` |
| `tensorboard` | `true` | 写 `tb/` |
| `graph` | `false` | 把模型计算图写进 TensorBoard（trace 一次前向） |
| `wandb` | `false` | 打开后需 `WANDB_API_KEY`（本手册未验证该路径） |
| `wandb_project` | `my_trainer-template` | wandb 项目名 |

### `[sample]` / `[bench]` / `[sweep]`

| 小节 | 字段 | 默认 | 说明 |
|------|------|------|------|
| `[sample]` | `ckpt` | `""` | 空 = `runs/<run.name>/ckpt.pt` |
| | `prompt` | `"\n"` | 起始文本（字符级数据按字符编码） |
| | `max_new_tokens` | `200` | 生成长度 |
| | `temperature` | `1.0` | 采样温度 |
| | `top_k` | `0` | `0` = 不截断 |
| `[bench]` | `iters` | `10` | 计时步数 |
| | `warmup` | `3` | 预热步数（不计时） |
| `[sweep]` | `name` | `sweep` | 汇总目录名：`runs/<name>/` |
| | `mode` | `grid` | `grid` 全组合 / `random` 随机采样 |
| | `space` | `{}` | 形如 `{ "optim.lr" = [1e-3, 3e-4] }` |
| | `num_samples` | `8` | 仅 `random` 模式 |
| | `seed` | `0` | 仅 `random` 模式 |

## 6. 示例配置

最小可跑（CPU，40 步，一分钟内）：

```toml
[data]

block_size = 128

[model]
name = "gpt"
block_size = 128
n_layer = 2
n_head = 2
n_embd = 64

[optim]

[train]

eval_interval = 20
eval_iters = 5

[run]

```

完整的带注释模板：**`docs/training-template/config.template.toml`**（56 个字段全覆盖，写的全是默认值，复制改一处就能跑）。

`configs/` 下已备好五份可直接运行的：`debug_cpu.toml`（CPU 冒烟，2 层 40 步）、`shakespeare_char.toml`（单卡 6 层 GPT，`device="cuda"`、`amp="bf16"`、5000 步）、`gpt_v0.toml`（`gpt_v0` 模型 + `torch.compile`）、`gpt_v1.toml`（`gpt-v1` 模型 + GPT-2 BPE 的 `shakespeare` 数据）、`sweep_lr.toml`（2×2 网格：`optim.lr` × `model.n_layer`，CPU 20 步）。

## 7. 常见任务

### 冒烟测试（确认环境没问题）

```sh
python -m my_trainer.train configs/debug_cpu.toml
```

### 加一个新模型

两步，都在你自己的文件里，不用改 my_trainer 源码。

1. **写模型**：复制 `src/my_trainer/models/toy_rnn.py`（包内）或 `src/gptv1.py`（仓库根 `src/` 下），保留 `__init__(cfg, vocab_size)`、`forward`、`generate`、`num_params`，并在文件里用 `@register_model("名字")` 标在构建函数上；
2. **列进配置**：`[model] location = "src/my_models.py"`（相对仓库根）+ `name = "你的注册名"`；`location` 非空会在建模型前 import 该文件。

`@register_model` 只是往注册表塞一项，模块不被 import 就不会执行——`[model] location` 就是替你 import 的那一步。
漏了会在启动时报「未注册的模型 xxx，可用项：[...]」。

训练器、采样、bench、`compile`、`graph` 都不用改（`ToyRNN` 就是这样接进去的，49 行）。

### 换数据集

1. 准备 `data/<名称>/{train,val}.bin`（`uint16`）与可选 `meta.pkl`；
2. 配置写 `[data] name = "<名称>"`。

### 换分词器

数据的 id 空间、模型 embedding 宽度、采样时的解码三者必须同源。`[data] tokenizer` 决定后两者：

```toml
[data]
name = "shakespeare"
tokenizer = "tiktoken:p50k_base"   # 必须和准备数据时用的编码一致
```

|写法                |什么时候用                                                                 |
|------------------|----------------------------------------------------------------------|
|`""`（默认）          |字符级数据（有 `meta.pkl`），或 GPT-2 BPE 数据（`prepare.py` 用的就是 gpt2）            |
|`tiktoken:<名字>`   |用 tiktoken 换过编码的数据；`gpt2`(50257) / `r50k_base` / `p50k_base`(50281) 可用|
|`hf:<仓库 id 或本地目录>`|HuggingFace tokenizer（如 `hf:bert-base-uncased`），首次需要网络；本仓库未验证         |
|`<自定义类型>:<参数>`    |用 `@register_tokenizer` 注册过的分词器类型                                     |

准备数据时用的是哪个分词器，配置里就必须写哪个——写错不会报错，只会让采样输出乱码（loss 看起来还正常）。
用 tiktoken 重新准备数据的最小做法：复制 `data/shakespeare/prepare.py`，把 `get_encoding("gpt2")` 换成目标编码。
`vocab_size` 自动取分词器词表大小，不需要写进配置。

词表上限：`.bin` 以 `uint16` 存 token id，所以**词表必须 ≤ 65535**。`cl100k_base`（100277）、`o200k_base` 这类会在加载数据时直接报错——要支持得把 prepare 脚本和读取端一起换成 `uint32`，当前模板不支持。

### 自己训练的分词器

`[data] tokenizer` 的类型是开放的：写一个类满足 `my_trainer.protocols.Tokenizer`（`vocab_size` + `encode` / `decode`），
再注册一个「参数 -> Tokenizer」的构建函数，冒号后面那一段参数原样传给构建函数（可含 `/`、`:`）：

```python
# src/my_tokenizer.py
from my_trainer.protocols import Tokenizer
from my_trainer.registry import register_tokenizer


@register_tokenizer("mine")  # 配置里写 "mine:任意参数"
def build(param: str) -> Tokenizer:
    tok = ...  # 自己训练好的分词器，param 通常是它的路径
    return Wrapper(tok)  # 提供 vocab_size / encode / decode 三样即可
```

```toml
[data]
tokenizer = "mine:data/mydata/tokenizer.json"
tokenizer_location = "src/my_tokenizer.py"   # 相对仓库根；import 时注册 "mine"
```

数据按 `data/<name>/{train,val}.bin`（`uint16`）准备，id 空间必须与你的分词器一致（词表同样受 65535 上限约束）。
准备数据这一步模板不管：自己用同一个分词器把文本编码成 `train.bin` / `val.bin` 即可（参照 `data/shakespeare/prepare.py`）。

### 从零重跑 / 续训

```toml
[run]
resume = "auto"    # 三选一：auto | none | 存档路径
```

- `"auto"`（默认）：有 `ckpt.pt` 就从它的下一步继续。
- `"none"`：忽略已有存档，从头跑（会覆盖同名目录里的存档）。
- `"runs/别的实验/ckpt.pt"`：从指定存档接续；路径不存在会在启动时报错。

续训日志会打印：`接续 runs/debug-cpu/ckpt.pt：从第 40 步继续，历史最好 val loss 3.2257`。
存档里的模型结构与当前 `[model]` 不一致时会直接报错并提示换回对应配置，不会静默加载一半权重。

### 复现某次实验

```sh
cp runs/debug-cpu/config.toml my_repro.toml   # 可改 [run] name，避免覆盖原产物
python -m my_trainer.train my_repro.toml
```

### 调超参

没有命令行覆盖：复制配置、改一处、跑。批量对比用 `sweep`。

### 找学习率（sweep）

```toml
[sweep]
name = "lr-nlayer"
mode = "grid"
space = { "optim.lr" = [3e-4, 1e-3], "model.n_layer" = [2, 4] }
```

```sh
python -m my_trainer.sweep configs/sweep_lr.toml
```

每组实验写到 `runs/<sweep.name>/<run_id>/`（目录名即超参，如 `n_layer=2__lr=0.001`），可覆盖的键只能是 `小节.字段`，启动时会一次性校验。结果：

```
| run_id | optim.lr | model.n_layer | val_loss | val_accuracy | status |
|---|---|---|---|---|---|
| n_layer=2__lr=0.001 | 0.001 | 2 | 3.51348 | 0.161133 | ok |
| n_layer=1__lr=0.001 | 0.001 | 1 | 3.53571 | 0.157878 | ok |
```

同时生成 `summary.csv` 与 `summary.md`（按 val loss 升序，失败组 `status=error`）。

### 开 torch.compile 加速

```toml
[train]
compile = true
```

本机实测（14M 模型、3070 Ti、batch 32×256）：87.8 → 49.7 ms/step，1.77x，代价是首次前向多花几十秒。
存档、加载、采样走的是**未编译**的模型，所以开着编译存的 ckpt 关掉编译也能直接续训（已验证双向切换）。

### 看模型结构图

配置打开开关，跑任意一次训练（哪怕只有 1 步）：

```toml
[log]
graph = true
```

```sh
python -m my_trainer.train configs/gpt_v0.toml
tensorboard --logdir runs      # 打开 Graphs 面板
```

说明：写进去的是 **trace 出来的前向 op 图**（用 1 个样本、只在推理路径上），所以
- 只能看到一个具体形状（batch=1、block_size 固定），动态长度看不到；
- `generate` 里的采样循环不在图内（不在 `forward` 里）；
- 不含反向/梯度图；
- 同一个 run 重复训练会重复写同名 tag，TensorBoard 显示最新一张。

想要更好看、能点开每层看参数的图，导 ONNX 再用 Netron 打开：

```python
import torch
from my_trainer.build import build_all
from my_trainer.configs import Config
cfg = Config.load("configs/gpt_v0.toml")
device, dataset, model = build_all(cfg)
x = torch.randint(dataset.vocab_size, (1, cfg.data.block_size), device=device)
torch.onnx.export(model, (x,), "model.onnx", input_names=["idx"], output_names=["logits"])
```

（`torch.onnx.export` 需要额外安装 `onnx` 或 `onnxscript`，本仓库默认没装。）

不想装依赖的话，也可以走 TorchScript：`torch.jit.trace` 存成 `.pt`，Netron 同样能直接打开。

```python
import torch
from my_trainer.build import build_all
from my_trainer.configs import Config
cfg = Config.load("configs/gpt_v1.toml")
_, dataset, model = build_all(cfg)
model = model.to("cpu").eval()
x = torch.randint(0, dataset.vocab_size, (1, cfg.data.block_size))
y = torch.randint(0, dataset.vocab_size, (1, cfg.data.block_size))
with torch.no_grad():
    traced = torch.jit.trace(model, (x, y))   # 带 targets：图里含 loss 节点
traced.save("model.pt")                      # 含权重，文件偏大，看完可删
```

只 trace 推理路径时（`model(x)` 返回 `(logits, None)`）必须先包一层只返回 logits 的模块，否则 trace 会报 `Only tensors, lists, tuples of tensors…`。

## 8. 排错

| 提示 | 原因 | 处理 |
|------|------|------|
| `只接受一个配置文件路径，收到多余参数：['extra.pth']` | 多传了参数 | 只给配置文件路径 |
| `[train] 里出现了未知配置项 'max_iter'，是不是想写 'max_iters'？` | 键名拼错 | 按提示改名；注意没有 `--set` |
| `[optim] lr 需要数字，收到 'high'` | 类型不符 | 按默认类型写（数字不加引号） |
| `[train] amp="fp16" 需要 GPU；CPU 上请用 bf16 或 none` | fp16 依赖 CUDA | 改 `bf16` 或 `none` |
| `[sweep] optim 里没有 'lrr'，是不是想写 'lr'？` | space 键名错 | 写 `小节.字段` |
| `存档 ... 与当前配置不匹配（结构或参数量不同）` | `resume` 指向了别的模型/规模的存档 | 换回对应配置，或 `resume = "none"` |
| `缺少 data/shakespeare_char/train.bin ...` | 数据没准备 | 跑对应 `prepare.py` |
| `找不到根目录 model.py：请在仓库根目录运行` | 不在仓库根启动 | `cd` 到仓库根再执行 |
| `找不到存档 runs/.../ckpt.pt：先跑 python -m my_trainer.train` | sample 前没训练 | 先训练，或把 `[sample] ckpt` 指向已有存档 |
| `uv run` 报 `Expected a Python module at: src/nanogpt/__init__.py` | 发行名是 `nanogpt`，包目录却是 `src/my_trainer` | `pyproject.toml` 里已有 `[tool.uv.build-backend] module-name = "my_trainer"`，缺了就加上 |
| `error: Failed to spawn: my_trainer.train` | 把模块名当命令 | 写 `uv run python -m my_trainer.train ...` |
| `未注册的模型 'xxx'，可用项：['gpt', ...]` | 模型模块没被 import | 在 `[model] location` 写实现源码，或核对 `[model] name` |
| `未注册的分词器类型 'xxx'，可用项：['hf', 'tiktoken']` | 同上 | 在 `[data] tokenizer_location` 写实现源码 |
| `[model] location 需要一个存在的 .py 路径（相对仓库根）` | 路径写错 / 不是 `.py` | 写对路径（`[data] tokenizer_location` 同样规则） |
| `[model] location 加载 'x.py' 失败：...` | 源码文件自身 import 时报错 | 按冒号后的原因修源码（`[data] tokenizer_location` 同样） |
| `[data] tokenizer 需要写成 "<类型>:<参数>"` | 少了类型前缀，或冒号后为空 | 写 `tiktoken:gpt2` 这种；自定义类型先注册 |
| `分词器词表 100277 超过 65535 ...` | 词表超出 `uint16` | 换 ≤ 65535 的词表（`gpt2` / `r50k_base` / `p50k_base` / 字符级） |

## 9. 已知限制

- **单卡**：不做 DDP/分布式检查点（训练循环里留了扩展注释）。
- **无命令行覆盖**：改任何超参都要动 TOML，这是刻意的取舍。
- **单文件存档**：只保留最新 `ckpt.pt`，不滚动保留历史；`best_val_loss` 记在文件里。
- **`[data] reader="hf"`**：会一次性把文本编码进内存，只适合小语料；本机未联网验证。
- **wandb 路径**：默认关闭，未在本次验证中开启。
- **`python -m my_trainer.sweep`**：每组都从头跑（内部强制 `resume="none"`），重跑会覆盖同名目录里的产物。
- **自定义源码**：只认 `[model] location` / `[data] tokenizer_location`，不扫描目录（根目录 `train.py` 一 import 就跑，扫描不安全）；路径按仓库根解析，同一文件被两处引用只 import 一次；文件里不能用相对 import。

## 10. 与根脚本的关系

根目录 `train.py` / `sample.py` / `bench.py` / `model.py` / `configurator.py` / `config/` 完全保持原样，两边可以并存：根脚本用 `configurator.py` 的 `--key=value`，模板用 TOML。旧 console script（`nanogpt`，只打印问候语）已随包重命名删除，现在只有 `python -m my_trainer.*`。设计文档：`docs/training-template/01-需求理解.md`、`02-方案设计.md`。
